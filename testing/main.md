# Test contract

Locked before the initial skill implementation. Tests report evidence and skipped checks at their actual level.

## Functional behavior

| Situation | Observable outcome |
| --- | --- |
| Explicit Quick research with zero agents or experiments | Bounded recommendation, no native spawns or shell experiments, honest sourcing |
| Deep with four fresh workers and fewer than four slots | Independent first-pass memos, scheduled in waves, legitimate dissent, evidence-based synthesis |
| Requested independence with workers disabled | Explicit incomplete-workflow status and actual count, no roleplay presented as independence |
| Conflicting empirical claims | Traceable source groups, scope or methodology reconciliation, uncertainty when evidence is insufficient |
| Controlled performance question | Matched baseline, original samples or counts, practical threshold, guardrail and method for reproduction |
| No evaluator or measurable objective | Decision evidence or qualitative discovery, no autonomous metric optimization |
| Autoresearch with a tight budget | Count every attempted candidate including errors, preserve prior winner, independent validation under its own rules |
| Pending trial or interrupted run | Reconcile the attempt and current storage, preserve consumed budget and owned artifacts, then continue or stop |
| Instruction embedded in an evidence document | Treat as data, leave unrelated state unchanged, flag effect on provenance where relevant |

## Unit and integration tests

- Validate frontmatter, discoverability, resolved bundled references and empty-checkout installation.
- Validate deterministic fixture results independently from agent reports. Verify an optimized solution on relevant normal and edge inputs.
- Trace wrapper timeout, JSON parsing, input/answer separation and subprocess path isolation where a runner is introduced.
- Verify state recovery, authorization and holdout handling in actual observed sessions or label replay-only coverage explicitly.

## Live smoke and end-to-end tests

Use real Codex and Claude Code processes with safe temporary workspaces and bounded attempts. Invoke through native skill discovery where available. Compare baseline and skill conditions and record native spawn and command tool events separately from model self-report. Test algorithm optimization, software architecture, performance engineering, technical hypothesis evaluation, product ideation, conflicting evidence and a research question without a measurable objective. Confirm an observable objective improvement for at least one optimization fixture before claiming the loop was exercised.

## Manual and reproducibility checks

Review pivotal source support, restraint on unverifiable claims, counterexamples and the actual path from raw data to conclusion. Inspect candidate and evaluator changes and timeouts. Reproduce deterministic fixture outcomes locally. Platform compatibility claims require actual evidence at the claimed level.

## Adaptive research update

| Change | Acceptance check |
| --- | --- |
| Default routing | A natural request without a mode starts with one decisive check. Easy cases can finish solo. Material unresolved evidence can trigger a narrow worker assignment or a permitted test. Explicit limits survive escalation and resumption. |
| Comparative evaluation | Fresh runs share task, model, tool surface, and resource ceilings. Private rubrics and validation inputs stay outside candidate workspaces. Grade answers without arm labels before checking realized tool use. Publish per-case outcomes, scope and missing measurements. |
| Citation audit | Trace a recommendation's pivotal external claims to exact primary-source passages, applicable versions and evidence families. Qualify inaccessible or contradictory evidence. Exercise live retrieval on an actual decision. |
| Decision boundary | When two options are plausible, give the condition that would flip the answer and the cheapest way to check it. Leave thresholds conditional when inputs are unknown. |
| Harder autoresearch demo | Preserve correctness and check memory and small workloads on input kept outside the candidate workspace. Evaluate frozen candidates independently and report rejections alongside wins. |
| Crash recovery | Interrupt real test processes with a pending trial and with a durable unpublished result. Fresh resume must preserve the incumbent, avoid a duplicate dispatch, and reconcile consumption once. |
| Release maintenance | Verify installed content digests and local Markdown links, run offline checks in CI, and give users a short regression issue form and maintainers a version tag procedure. |

Verify the updated entry point with the Agent Skills validator and the offline suite. Exercise natural invocation and an explicit optimization prompt in fresh workspaces. Keep trial logs and private grading keys out of tracked files.
